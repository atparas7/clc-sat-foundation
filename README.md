# CLC SAT FOUNDATION

Skeleton of the CLC SAT site: same navigation, sections and file structure as `clc-sat-prep`, with all content removed.
Every test link opens a "Content coming soon" placeholder page, ready to be filled in.

- `index.html` — the app (sign-in, English / Math / Full Test sections)
- `practice/`, `vocabulary/` — placeholder pages, one per test
- `theory/`, `assets/`, `media/` — empty folders for PDFs and figures
